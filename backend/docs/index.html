Digital Approval Workflow API

Phase 3 API reference for auth, request creation, approvals, filtering, and pagination.

Swagger spec: /api/docs/swagger.json

Postman collection: postman/Digital_Approval_Workflow_Phase2.postman_collection.json

Core Endpoints

Method Endpoint Purpose
POST /api/auth/signup Create employee or manager account
POST /api/auth/login Authenticate and return JWT token
POST /api/requests/create Create employee request
GET /api/requests?advanced=true&search=loan&status=pending&page=1&pageSize=6 Manager search, filtering, and pagination
PATCH /api/requests/:id/status Approve or reject request
